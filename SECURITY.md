# Security Policy

## Supported versions

We patch security vulnerabilities in the latest release of the Multiverse Echoes Client. Older releases do not receive patches; upgrade to remain protected.

## Reporting a vulnerability

**Do not file security issues publicly on GitHub.**

Email **privacy@echolabs.me** with subject `Security:`.

Include:
- Description of the vulnerability.
- Steps to reproduce.
- Affected version of the client.
- Proof-of-concept code if available.
- Your name (or alias) for credit if you want public acknowledgement.

We respond within 5 business days. Triage within 10 business days. Patch within 30 days for critical issues; 90 days for lower severity.

## Disclosure

We follow coordinated disclosure. We ask reporters to give us 90 days to ship a fix before public disclosure.

## Out of scope

- Vulnerabilities in third-party dependencies (report upstream).
- Issues requiring physical access to the user's machine.
- Social engineering attacks.
